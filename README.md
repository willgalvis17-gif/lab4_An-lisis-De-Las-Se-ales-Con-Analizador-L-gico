# lab4_An-lisis-De-Las-Se-ales-Con-Analizador-L-gico
Laboratorio de Comunicaciones Digitales (UMNG): análisis de tramas UART con Raspberry Pi Pico 2W y analizador lógico. Incluye medición de tiempo de bit, decodificación con Logic 2 y estudio de sensibilidad al muestreo (25 kS/s–12 MS/s) para 1200, 9600, 57600 y 115200 baudios.
